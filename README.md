## Kesimpulan
Berdasarkan praktikum yang dilakukan, JavaScript dapat digunakan untuk membuat halaman web menjadi lebih interaktif melalui penggunaan variabel, function, operator aritmetika, percabangan, perulangan, serta manipulasi DOM.

Melalui latihan dan eksperimen mandiri, diperoleh pemahaman mengenai penggunaan `prompt()`, `alert()`, `console.log()`, validasi form, perhitungan otomatis, dan pengaturan tampilan elemen HTML menggunakan JavaScript.
